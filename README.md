# Танчики — Battle City

Браузерная версия с защитой базы, волнами по 20 врагов, четырьмя типами танков, звёздами, бонусами и локальным режимом двух игроков. Это самостоятельная реализация по мотивам NES; идентичность всех таймингов оригиналу не заявляется.

## Запуск

Сборка и зависимости не нужны: `python3 -m http.server 8765`, затем http://localhost:8765. Для проверки механики: `node tests/mechanics.cjs`.

## Управление

- Один игрок: WASD или стрелки, пробел — огонь. P — пауза.
- Два игрока: первый — WASD/пробел, второй — стрелки/Enter.
- На iPad палец можно вести по крестовине; другой палец удерживает A или B для огня.
- Редактор: нажимать/вести по полю; B меняет материал, START запускает карту.

## Правила

- Звезда ускоряет снаряд, затем даёт два снаряда одновременно и пробитие стали. Скорость танка от звезды не меняется. Улучшения сохраняются между этапами до потери танка.
- Basic медленный, Fast быстрее игрока, Power быстро движется и стреляет, Armor выдерживает четыре попадания.
- Красные танки выпускают бонус при первом попадании. Граната уничтожает врагов без дополнительных очков за каждый танк.
- Дружественный огонь оглушает второго игрока, не отнимая жизнь.
- После уничтожения 20 врагов и короткой задержки выводится результат, затем автоматически начинается следующий этап.

Карта и состав волн основаны на четырёх картах из newagebegins/BattleCity. При дальнейшем прохождении карты повторяются. Лицензия и авторство данных: [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
