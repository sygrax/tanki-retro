# Танчики

Браузерная аркада в духе классических танков: защита штаба, разрушаемые стены, волны врагов и экранные кнопки для телефона.

Откройте index.html в браузере. Сборка и установка зависимостей не нужны.

Управление: WASD или стрелки — движение, пробел — выстрел, P — пауза.

Для публикации на GitHub Pages выберите Settings → Pages → Deploy from a branch → main → / (root).
